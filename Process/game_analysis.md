# Extra Credit - Game Analysis: Lovers In  A Dangerous Spacetime

## Contextualization

Lovers in a Dangerous Spacetime is a video game released in 2015. 
It was developed by Asteroid Base which is a Toronto-based indie studio that is made up of 3 friends: Matt Hammill, Jamie Tucker, and Adam Winkels.
Matt Hammill once said that the development of this game was "almost an accident". 
The team had just the intention of making a game for a 3-day game jam. 
After the game jam, however, the team wanted to continue developing the project and so Lovers in a Dangerous Spacetime became an actual long-term project.
This game was a true passion project, and you can sincerely feel the love and joy that was poured into it.

Lovers in a Dangerous Spacetime is a space action platform shooter that can be played single-player or multiplayer that truly feels like it embodies the 2010's couch co-op revival
